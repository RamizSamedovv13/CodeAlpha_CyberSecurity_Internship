Phishing fundamentals

Phishing is a social-engineering attack where a criminal pretends to be a trusted party to trick you into revealing credentials, paying money or running malware.

  1. Bait – a convincing message (email, SMS, call).
  2. Hook – a link, attachment or request.
  3. Capture – credentials, payment or malware delivery.
  4. Abuse – account takeover, fraud, further attacks.

Prevention and response

Best practices

  • Check the sender's real domain, not just the display name.
  • Preview link destinations; type known addresses yourself.
  • Use a password manager and unique passwords.
  • Enable MFA, preferably phishing-resistant (passkeys, security keys).
  • Keep software updated; never enable macros from unknown files.
  • Verify unusual requests through a separate, trusted channel.

If you clicked

  1. Disconnect from the network if you opened a file.
  2. Change affected passwords from a trusted device.
  3. Enable or reset MFA and review account activity.
  4. Report to your IT/security team.
  5. Run a security scan and watch for odd activity.
